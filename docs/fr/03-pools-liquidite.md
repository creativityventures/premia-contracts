# Pools, dépôts et liquidité

Les pools mutualisent la liquidité disponible pour les options et calculent les parts des fournisseurs. Les flux de dépôt, retrait, commission et utilisation de la liquidité doivent rester cohérents avec les positions ouvertes.

L’architecture sépare les paramètres de pool, les tokens et les calculs de prime. Cette séparation facilite les intégrations mais rend la configuration et les autorisations déterminantes.
